# Bellbird Support Services (React + Vite)

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

- `src/components/`: one file per section (Header, Hero, About, Supports, ...)
- `src/data.js`: services and steps copy
- `src/styles.css`: all styling, with colour tokens at the top
- `public/hero.jpg`: photo used in hero slide 1 and the Welcome section (replace with your own)
- Hero slides 2 and 3 are SVG scenes in `src/components/Scenes.jsx`
- Placeholders to replace: phone, email, NDIS registration number, testimonials, and the form submit handler in `Contact.jsx`
